# WebScriptLog

WebScriptLog is a web-based tool for collecting and analysing writing-process data.

In the recording view, a writer enters a code, starts a session, and writes in a text area. During the session, the tool logs process data such as text changes, key events, cursor movement, pauses, and in some versions also window interaction and image-cover events.

The recorded data is stored as structured log files and can later be replayed, inspected, and analysed. The analysis side of the tool supports both detailed event inspection and more compact process representations, including a linear “writing score” that can be replayed and validated.

The overall purpose of the tool is to support research on writing behaviour: not only what final text was produced, but how it was produced over time.
